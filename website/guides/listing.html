Ozon / Wildberries 通用上架教程

本教程面向使用 JLC GLOBAL 的中国卖家。基本顺序是：连接目标店铺 → 采集商品 → 核对规格、类目和售价 → 开始任务 → 查看生成内容与平台结果。JLC GLOBAL 是独立卖家工具，与 Ozon、Wildberries 无隶属关系。

更新日期：2026 年 10 月 16 日。本文为文字操作指南，具体字段与可用操作以当前工作台提示为准。

开始前：准备账号、商品资料和生成费用

准备可正常使用的 JLC GLOBAL 账号、你的 Ozon 或 Wildberries 店铺连接信息，以及真实商品的图片、规格、材质、尺寸和重量。首次操作建议先选一个资料完整的商品，走完流程后再处理更多商品。

使用邮箱注册并登录后，可支付 ¥9.9 开通一天试用，每账号限一次。试用费仅开通使用权限，文案和图片生成另行收费，不包含在 ¥9.9 试用费内。月卡、季卡及续费请联系客服，以实际账号开通页面为准。开始生成前，确认自己使用的生成服务及其计费说明；不清楚费用时，先通过官网客服核实。

第一步：连接并选择目标店铺

  1. 登录 JLC GLOBAL 工作台，进入店铺管理，选择“添加店铺”。
  2. 按目标店铺选择 Ozon 或 Wildberries，填写对应平台的连接信息。Ozon 使用 Client-Id 与 API-Key；Wildberries 按表单填写对应的 API 令牌，并核对页面提示的权限。密钥只填写在店铺连接表单中，不要放进商品文案或公开截图。
  3. 检查连接结果。如果显示待复验或连接失败，先按提示检查凭据与权限。店铺连接正常后，再到采集箱为商品选择目标店铺。

保存目标店铺不等于开始上架。启动前仍需核对该商品的类目和规格资料。

第二步：从 1688 采集商品，在采集箱核对

  1. 使用 JLC GLOBAL 浏览器插件采集目标 1688 商品，回到工作台的“采集箱”查找对应记录。采集准备可参考1688 商品采集与上架准备。
  2. 对照来源商品核对标题、源图与规格。多规格商品要逐个检查颜色、尺寸、数量及对应图片，避免把不同规格混在一起。
  3. 缺少材质、尺寸或包装数量等事实时，先向供货方确认。采集到的数据也需要复核，不能把 AI 推测当作商品实测信息。

第三步：确认目标店铺、类目和每个规格的价格

  1. 在商品卡片的“目标店铺”区域选择要发布的目标店铺，确认选择已保存。
  2. 按商品的实际用途确认目标平台的类目，并根据页面提示补齐必填资料。相似名称不代表同一类目；不能为了通过检查随意选不相关的类别。
  3. 在“尺寸 · 重量 · 价格”区域逐个核对规格，注意字段显示的单位与币种。不要把采购价直接当成目标售价，也不要只改第一个规格。
  4. 需要核对类目属性或其他资料时，使用“编辑字段”。修改后保存，并确认页面没有提示保存失败或缺少必填项。

启动前自查：店铺是否正确、规格与图片是否对应、类目是否匹配、尺寸重量是否真实、每个规格售价是否确认。

第四步：点击“开始任务”，查看文案、图片和进度

确认准备信息后，点击该商品的“开始任务”。任务会按当前配置处理商品资料、俄语文案、图片和后续发布环节。这不是只生成预览的按钮，后续流程可能继续向目标店铺提交商品。请在启动前确认目标店铺和商品资料。

在采集箱查看任务进度和陆续出现的产出内容。核对俄语文案是否保留真实规格、数量和用途；核对生成图是否保持商品外观、配件和包装数量一致。AI 图片不能作为商品事实依据。

发现内容不符时，先使用页面提供的“停止任务”，确认实际停止状态及是否已经提交，再按当前可用操作处理。停止并非立即撤回：它可能需要等到安全节点，已经提交的平台商品也不会因此自动撤销。需要继续时，按页面提示使用原任务的“继续任务”。

第五步：区分任务进度、提交回执和平台商品状态

图片生成完成、任务有进度、平台收到提交，都不能单独证明商品已经可售。提交后还要结合平台回执和 对应平台卖家后台里的实际商品状态核对。

  • 正在处理：查看当前步骤与提示，先确认是生成、提交还是等待平台处理。
  • 提示缺少资料或平台拒绝：根据具体错误核对对应规格、类目或属性，修正后使用页面允许的后续操作。
  • 结果未知或待核对：先检查原任务回执和 对应平台后台，不要立刻重新采集、另建任务或重复上传同一商品。
  • 平台已接收或审核中：继续查看目标店铺的处理结果。最终是否可售，还需核对平台显示的审核、价格、库存等情况。

需要客服协助时，提供商品或任务编号、发生时间及错误文字，并说明 对应平台后台是否已出现该商品。不要公开账号密码或 API-Key。

Ozon 与 Wildberries：共同流程，分别核对平台要求

两个平台都按“采集 → 核对 → 开始任务 → 查看结果”的顺序操作，店铺连接、类目属性和平台结果需要分别确认。

  • 店铺连接：Ozon 填写 Client-Id 与 API-Key；Wildberries 填写对应 API 令牌。分别检查目标店铺的连接状态和权限。
  • 类目与属性：在工作台选择对应平台类目，按其提示补齐必填字段。不要把 Ozon 的类目编号或属性选项直接套到 Wildberries，也不要反向套用。
  • 提交结果：分别进入对应店铺后台核对商品记录和处理结果。平台收到提交不等于商品已经可售；一个平台成功也不能证明另一个平台成功。
  • 经营数据：本文后面的财务对账和搜索可见性说明针对当前 Ozon 功能，不代表 Wildberries 已具备相同报表。

手机随时处理上架，电脑接着工作

用手机浏览器登录 JLC GLOBAL，可在采集箱处理已采集到云端的商品，核对资料、启动上传上架任务并查看进度。回到电脑后登录同一账号，找到同一商品即可继续处理；不需要为了换设备重新采集或重复启动。

换设备前先保存修改并确认保存成功。已提交的云端任务会继续处理；尚未保存的输入不应当作已经同步。1688 浏览器插件采集按插件支持的环境操作。财务对账、搜索可见性及部分多列表格页面请在电脑上查看。

上架之外：利润预算、财务报告和搜索表现

利润预算：先试算售价与物流

在采集箱商品卡片打开“利润计算 · 试算售价与物流”，核对带入的包装资料和费用，修改售价查看预计利润。试算不会启动任务。预算取决于填写的成本和计算条件，不等于最终实际利润。

财务报告：查看 Ozon 平台结算

在电脑端进入“财务对账”，选择店铺和账期，查看平台结算与本期支出明细。这些金额尚未扣除采购成本，实际到账应与收款记录核对；人民币折算取决于设置的汇率。当前该页展示 Ozon 数据，WB 财务尚未接入。

店铺搜索表现：查看曝光到成交

在电脑端打开“搜索可见性”，按店铺查看搜索内曝光、搜索进店、商品页曝光、加购与成交等可用指标，也可查看商品表现和进店趋势。这些数据帮助你判断商品被看到后有没有进一步转化；具体可用数据以页面读取结果为准，不等于关键词搜索量或排名查询。

常见问题

¥9.9 是否包含文案和图片生成？

不包含。¥9.9 是一天试用的使用权限费用，每账号限一次；文案和图片生成另行收费。

商品采集后会立即上架吗？

不会因为保存店铺选择就自动开始。先在采集箱核对资料，再点击“开始任务”；启动后的流程可能继续生成并提交商品。

多规格商品只填一套价格和尺寸可以吗？

应逐个规格核对。不同规格可能有不同的价格、尺寸、重量和对应图片，不能默认第一套资料适用于全部规格。

生成图片与实物不一致怎么办？

先确认任务是否还在处理及是否已提交，停止后按可用操作修正。对照真实商品核对外观、材质、配件和数量，不要把不符实物的内容继续用于销售。

看见失败提示，能否直接重新采集再跑一次？

先读具体错误并核对原任务是否已经提交。结果未知时重复操作可能造成重复商品或新的生成费用；明确原因后再按页面提示处理，必要时联系客服。

工具能保证通过审核或获得销量吗？

不能。JLC GLOBAL 协助处理商品资料和提交任务，平台审核、可售状态与销售结果仍取决于实际商品、店铺和平台处理。
