Wildberries 店铺连接

添加店铺时选择 Wildberries，按表单填写对应店铺的 API 令牌，检查连接状态和权限。启动前确认商品选择了正确的目标店铺。

类目和属性

使用 Wildberries 对应的类目与属性，按工作台提示补齐必填资料；逐个核对商品规格、图片、尺寸重量和售价。不要套用另一个平台的类目编号或属性选项。

提交后如何核对

检查原任务回执，并到 Wildberries 店铺后台核对商品处理结果。提交已接收不等于商品已经可售；结果未知时先核对原记录，避免重复上传。

财务与搜索报表

当前教程里的财务对账与搜索可见性说明针对 Ozon；WB 财务尚未接入，不能视为两个平台报表相同。
