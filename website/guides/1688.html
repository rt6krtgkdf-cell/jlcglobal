1688 商品采集与上架准备

了解如何通过 JLC GLOBAL 浏览器插件整理 1688 商品资料，在云端工作台核对信息，并准备面向 Ozon、Wildberries 的俄语文案与商品图片。

1688 商品采集是什么？

JLC GLOBAL 将 1688 货源商品的信息与图片整理到云端工作台，作为制作俄语商品内容和向俄罗斯电商平台提交商品的准备资料。采集完成后，还需要核对内容并完成目标平台要求的资料。

开始前准备什么？

先注册并登录 JLC GLOBAL，确认账号开通状态。从官网“下载 JLC GLOBAL 插件”入口下载压缩包，解压后在 Edge 或 Chrome 扩展页开启开发者模式，选择“加载解压缩的扩展”，载入 edge-extension 文件夹。插件下载请以官网链接为准。

怎样准备商品资料？

先整理来源商品的信息和图片，再在工作台核对商品名称、规格、材质、尺寸、数量和图片对应关系。来源未明确的信息应向供应商核实，不应根据图片猜测。俄语文案与图片制作应以已确认的商品事实为基础。

采集后如何进入上架流程？

按照目标店铺和平台准备商品资料，制作并检查俄语内容，然后提交至 Ozon 或 Wildberries。两个平台的类目和属性要求不同，采集成功不代表已满足所有上架条件，也不代表平台已审核通过。

需要一直开着电脑吗？

浏览器插件采集需要在浏览器中操作。已提交到服务器的云端任务会继续处理，可以稍后重新登录查看进度。此说明不代表关闭浏览器后还能继续执行尚未提交的本地采集。

如何注册和开通？

使用邮箱注册并登录后，可支付 ¥9.9 开通一天试用，每账号限一次。试用费仅开通使用权限，文案和图片生成另行收费，不包含在 ¥9.9 试用费内。月卡、季卡及续费请联系客服，以实际账号开通页面为准。
