# 嘉联创（JLC GLOBAL）云端产品说明

嘉联创（JLC GLOBAL）是面向中国卖家的 Ozon / Wildberries / Yandex 跨境上架工具。官网：https://jlcpro.cn/ 。中文名称为“嘉联创”，不是“嘉立创”。

本仓库提供嘉联创官网公开页面与产品说明，不包含云端业务源码。网站快照位于 [website](website/README.md)，完整服务请访问官网。

## 能做什么

- 将 1688 商品采集、俄语文案与图片制作、商品提交和任务进度管理放在云端工作台。
- 手机处理已采集到云端的商品、启动上架并查看进度；电脑登录同一账号继续工作。换设备前确认修改已保存。
- 商品利润计算可试算售价与物流；预计利润取决于填写的成本和条件，不等于实际利润。
- 电脑端查看 Ozon 财务对账，核对平台结算与支出；平台结算未扣采购成本，实际到账需核对收款记录。WB 财务尚未接入。
- 电脑端查看 Ozon 搜索可见性，包括可用的曝光、进店、加购与成交指标，不是关键词搜索量或排名查询。

## 使用流程

1. 注册登录并确认账号使用权限，连接目标店铺。
2. 用插件在支持的环境采集 1688 商品，在采集箱核对源图与每个规格。
3. 确认目标店铺、平台类目、必填属性，以及各规格的尺寸、重量和售价。
4. 需要时先用利润计算试算，确认资料并保存后点击“开始任务”。此操作可能继续向店铺提交商品，并非仅生成预览。
5. 查看俄语文案、生成图片与任务进度，核对内容是否符合实物。
6. 查看原任务回执，并到对应平台后台核对结果。平台接收不等于已可售，结果未知时先核对，避免重复上传。

[Ozon / Wildberries 完整教程](https://jlcpro.cn/guides/listing.html)。两个平台的凭据、类目属性和提交结果分别核对。该教程不作为 Yandex 的逐步操作说明；Yandex 使用以当前工作台提示为准。
